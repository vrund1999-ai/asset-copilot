# Skills this project demonstrates

asset-copilot is a portfolio project showing production-minded applied AI engineering for a
real estate investment setting: working with business teams, mixed data, and LLM agents where
accuracy and governance matter.

## Capabilities in scope

- Turn a business need into a clear technical plan with measurable outcomes.
- Build agents, data pipelines, and workflows over structured data, unstructured documents,
  external information, and user feedback.
- Hands-on Python, SQL, APIs, databases, LLMs, agents, and retrieval.
- Ship solutions that are secure, governed, and well-tested.
- Communicate progress, risks, and recommendations to technical and non-technical audiences.
- Prioritize accuracy and reliability when working with real-world data (spreadsheets,
  documents, databases).

## How the project maps to them

| Capability | Where it shows up |
|---|---|
| Structured + unstructured + feedback | Postgres tables, document RAG (M2), feedback loop (M3) |
| Agents with LLMs, SQL, APIs | Tool-use agent (M1), FastAPI service |
| Accuracy and reliability | Deterministic calc, cited answers, discrepancy detection, eval harness (M4) |
| Secure, governed, tested | SQL guard, read-only role, audit log, unit tests, CI |
| Business impact | Variance report workflow with measurable time savings (M3) |
| Communicating to stakeholders | Stakeholder memo, results tables, clear README (M5) |

## Implications for priorities

1. Evals and governance matter more than UI polish.
2. Every claim made about this project must be backed by something measurable in this repo
   (e.g. "X% accuracy on N questions"). Never claim production or business impact that did not happen.
3. Use CRE vocabulary correctly (NOI, rent roll, T-12, lease rollover, WALT, DSCR) so the domain
   interest is credible, but do not pretend to have industry experience.
